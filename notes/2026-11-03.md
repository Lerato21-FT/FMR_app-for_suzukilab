## How the VI was read

The VI is a compiled LabVIEW binary. Its front panel and block diagram are
stored as zlib-compressed sections. They were decompressed with .NET's
built-in `DeflateStream` (nothing installed), and the control labels, default
values, free-text comments, sub-VI names and SCPI strings were read from
them. The wiring itself is not readable this way. The sequence below is
reconstructed from labels and comments, so it should be confirmed against the
VI opened in LabVIEW. Extracted strings were kept in the session scratchpad
only, not in the repository.

## Calibration constants found on the panel

- Magnet: "H conversion (approx) (Oe/V)": about 996.3 Oe/V with one Kepco
  supply, about 1984.4 Oe/V with two supplies (up to 5 V). "H max" notes give
  9741 Oe (one supply) and 15905 Oe (two supplies).
- Gaussmeter correction: "H read scale" and "H read offset (Oe)", noted as
  "calibrated to 1.544, −11.956 on 08/20/2026" (an older note says 2020 10/12).
- Modulation: "Modulation H scale (Oe/V)" noted as 5.219 Oe/V at 700 Hz;
  modulation RMS field = SR830 sine amplitude × that scale.
- A warning: "If the starting field and H begin don't match, the conversion
  factors need recalibrating!"
- RF power is set in dBm (0 dBm = 1 mW, maximum 23 dBm = 200 mW).

## Measurement sequence (reconstructed)

1. Wait until **Measure** is pressed.
2. Initialize the SR830 (reference source, sine amplitude, reference frequency,
   time constant, sensitivity, reserve, auto-phase) and the Lake Shore.
3. Parse the comma-separated **Frequencies (GHz)** and **In-Plane Angles
   (deg.)** lists. **H orientation** is In-plane or Out-of-plane.
4. For each angle, move the stepper motor. Then for each frequency:
   - set the 83640B to CW at that frequency and turn RF power on;
   - estimate the resonance field from guesses for γ (MHz/Oe) and Meff,
     which centres the sweep window ("Hfmr Guess", "f/gamma", "4PiMeff",
     "H range");
   - ramp the field up to the start value ("Field ramp steps", "Field ramp
     wait (ms)"), then wait for the field to settle and the sample to
     saturate ("H saturate time");
   - step Aux Out from **AuxOut begin (V)** to **AuxOut end (V)** in steps of
     **AuxOut step (V)**, waiting **Time between H step (ms)** each time;
   - at each step, read H from the Lake Shore and X and θ from the SR830, and
     plot signal and phase against H live;
   - turn off the modulation and RF, ramp the field down to about 0 ("AuxOut
     ramp down step"), and wait at H = 0;
   - save the data.
5. After all angles, return the motor to its initial position, and beep if
   requested.
6. **Skip Current Measurement** abandons the current sweep. **Stop All** exits
   only after the field is ramped down and the data is saved.

## Saved data

Saved with Write To Spreadsheet File: tab-delimited, values formatted
`%.6e`, into a chosen folder (default `…\Documents\FMR Data`). The file name is
built from a prefix, the frequency in MHz, the orientation, the angle
(`%05.1f`) and a power/modulation string such as `+0dBm2.0OeRMS-`, ending in
`.csv`. For example: `prefix-10000MHz-In-plane-000.0deg-…csv`. Columns include
H field (Oe) and lock-in signal (V); phase is recorded too, and there is a
"Save Prf & Hmod?" option. This matches the input format the analysis app
expects (field in column 1, signal in column 2, frequency in the name).

## Proposed plan (not yet approved)

- Work on a feature branch, `fmr-acquisition`.
- `src/app/instruments/`: one driver per instrument (SR830, Lake Shore 425,
  83640B, Kepco via Aux Out, stepper). Each has a simulated version that
  produces a synthetic derivative-Lorentzian signal, so `make verify` runs
  without hardware. pyvisa with the pure-Python pyvisa-py backend is the
  proposed dependency.
- `src/app/measurement.py`: the sweep as a cancellable background task with
  Skip and Stop. The field is always ramped down safely, even after an error.
- `src/app/calibration.py`: Oe↔V conversions and the modulation RMS field.
  These are results, so they are computed in the backend.
- API: validated endpoints to start, skip, stop and check runs, a live data
  stream, and instrument identification.
- `src/web/`: a settings form and live plots of signal and phase against H.
- Saving: the same CSV format as LabVIEW, written to a `data/measurements/`
  mount. This departs from ARCHITECTURE.md's "no host bind mounts" rule.
- `docker/`, Makefile, `.env.example`, tests in `tests/2026-11-03/` or that
  day's folder, a rewrite of ARCHITECTURE.md and the README, and
  `docs/labview-fmr-setup.md`.
- Assumptions: v1 does single-angle sweeps without the stepper; calibration
  constants are editable settings, not hard-coded.
