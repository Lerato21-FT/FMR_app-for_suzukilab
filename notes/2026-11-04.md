# 2026-11-04 — Native host app, skeleton, run engine, API and page

## Decisions

- **No Docker.** The instruments are reached with PyVISA through NI-VISA on
  the Windows lab computer, which a container cannot use (TASKS.md Q2,
  option c). AGENTS.md and ARCHITECTURE.md were rewritten accordingly.
  Python packages live only in the repository's `.venv/`, and tool caches in
  `.cache/`.
- **GNU Make installed on the host** with explicit approval (Q1):
  `winget install ezwinports.make` 4.4.1, user scope. It lives under
  `%LOCALAPPDATA%\Microsoft\WinGet\Packages\…\bin`, on the user PATH, so new
  terminals find it. Recipes run in Git Bash's `sh`.
- **Removed:** `.dockerignore` (Docker only) and `.DS_Store` (macOS metadata).
  **Replaced:** the Makefile, README, `.gitignore` and `.env.example`.
  **Kept for your decision (Q7):** `PROMPT.md` and `docs/fmr-model.md`,
  which describe the earlier analysis app.
- **Dependencies:** `fastapi`, `uvicorn` and `pyvisa`; dev tools `pytest`,
  `httpx` and `ruff`. They are locked with hashes by `uv pip compile` (uv
  0.9.15 inside `.venv`) for Python 3.14 on win-amd64, and installed with
  `pip --require-hashes`.
- **Plotly 2.35.2** is fetched by `make vendor` from cdn.plot.ly and checked
  against a pinned SHA-256. The hash was recorded from the first download
  (trust on first use), not checked against a published checksum.

## What was built

- **Calibration:**
  - Aux Out ↔ field: 996.3 Oe/V, inverted.
  - Gaussmeter correction: `H = 1.544·raw − 11.956`. The formula is an
    assumption from the panel labels (Q5).
  - Modulation: 5.219 Oe/V rms.
  - Sweep and ramp voltage lists at 1 mV resolution.
  - Kittel resonance estimate: in plane and saturated out of plane, CGS.
- **Drivers:**
  - SR830: never sends `*RST`; uses `SNAP? 1,4` and `AUXV`.
  - Lake Shore 425: `RDGFIELD?`, at 57600 baud, 7 data bits, odd parity.
  - 83640B: the VI's SCPI strings.
  - Aux Out magnet: bounded ramps.
  - Simulated instruments: a derivative-Lorentzian line at the Kittel field.
- **Run engine:**
  - limits are checked, and file names checked for collisions, before
    anything is sent;
  - one run at a time, in a thread;
  - skip and stop;
  - safe shutdown in `finally`, every step attempted and every failure
    reported;
  - partial sweeps saved.
- **API and page:** described in ARCHITECTURE.md and the README.

## Tests (`tests/2026-11-04/`)

33 tests cover:

- **Calibration:** values and edge cases.
- **Drivers:** the exact command strings.
- **Run engine:**
  - a full run whose saved file recovers the simulated resonance;
  - failure mid-sweep, which still shuts down and keeps 50 points;
  - stop and skip;
  - limit rejection, with nothing sent;
  - no overwriting;
  - one run at a time.
- **API contract.**
- **Config.**

`smoke_check.py` runs the real uvicorn server over HTTP.

**Failing first:**

1. With `corrected_field_oe` and `estimate_resonance_field_oe` stubbed, 10
   tests failed.
2. With a deliberately wrong in-plane formula (4πM where 2πM belongs), 3
   tests failed. The independent Kittel check got 8.33 GHz back instead of 10.
3. After the fix, all 33 tests pass.

`make verify` (lint, test, smoke) is green.
