
## Task 10: SR830 time constant labels and the 3 τ rule

- The user asked to label the time-constant index ("8 = …") and to make sure
  τ is at most a third of the wait between field steps. Note: index 8 is
  100 ms on the SR830, not 300 ms (9 is 300 ms).
- The user chose the recommended answers: refuse the run (not just warn);
  default wait per step 200 → 300 ms; the rule uses the wait-per-step setting
  only (instrument read time comes on top); sensitivity becomes a labelled
  dropdown too; exactly 3 τ is allowed.
- `src/app/sr830_tables.py`: the OFLT table (10 µs to 30 ks) and the SENS table
  (2 nV to 1 V), with labels, plus `min_step_wait_ms` (3 τ rounded up to whole
  ms). `check_limits` adds the error, `Preview.min_step_wait_ms` reports the
  minimum, and `Defaults` sends both tables.
- Test shown failing first with the factor set to 1: 9 failures, all of them
  the 3 τ checks. It passes with the factor at 3. Tests that use fast
  simulated runs now set τ = 10 µs and a 1 ms wait, since 0 ms is refused.
- `make verify`: 107 tests passed, smoke check passed. The page was not
  checked in a browser, and no hardware was used.

## Task 11: clear message when the app is not running

- A "Request failed." the user saw came from the server being closed
  (`make run` terminal shut). `fetch` rejects with no HTTP answer, and the old

  `HTTP <code> <reason>: <text>` or `Page error: ...`. If the server was
